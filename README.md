# WrenbyAI

WrenbyAI is the FrameFX assistant: chat, web search with cited sources, Beta7 preset generation and tool use.

Trained on a 2021 ROG Zephyrus G14.

**Live:** https://ilikemacos.github.io/framefx-assistant/

Docs for FrameFX: https://ilikemacos.github.io/universal-framefx/

Needs an internet connection. Requests are rate-limited per visitor.
